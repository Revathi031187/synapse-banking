## 📊 Technical Architecture

### Data Flow

```
1. Data Generation
   ├─ banking_data_generator_5000.py
   ├─ Generates: customers.csv (5000 rows)
   ├─ Generates: products.csv (20 rows)
   └─ Generates: transactions.csv (~27K rows)

2. Backend Processing
   ├─ FastAPI loads data
   ├─ Agent A: K-Prototypes clustering
   │   ├─ Groups 5000 customers into 5 personas
   │   ├─ Generates unique names
   │   ├─ Enriches with image_mapper
   │   └─ Adds segment explanations
   ├─ Micro Agent: K-Means sub-clustering
   │   ├─ 4 sub-segments per persona
   │   ├─ LTV tier assignment
   │   └─ Detailed explanations
   └─ Agent B: Product recommendations

3. Frontend Display
   ├─ React + TypeScript
   ├─ TanStack Query for data fetching
   ├─ Tailwind CSS for styling
   └─ Framer Motion for animations
```

### API Architecture

```
GET  /api/banking/status
GET  /api/banking/datasets
POST /api/banking/datasets/load
POST /api/banking/agent_a/execute     → Generates 5 macro personas
GET  /api/banking/agent_a/results     → Returns personas with images
GET  /api/banking/macro-segments      → Formatted macro segments
POST /api/banking/micro-segments/{id} → Creates 4 micro segments
GET  /api/banking/micro-segments/{id} → Returns micro segments
GET  /api/banking/customers           → 5000 customers for Agent B
POST /api/banking/agent_b/execute     → Product recommendations
```
