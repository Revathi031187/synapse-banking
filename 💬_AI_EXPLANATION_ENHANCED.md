## 🔍 Data Integration

### Factor Scores Used:
```python
detailed_calc = product.get('detailed_calculation', {})
eligibility = detailed_calc.get('eligibility_score', {}).get('score', 0) * 100
need_match = detailed_calc.get('financial_need_match', {}).get('score', 0) * 100  
product_value = detailed_calc.get('product_value', {}).get('score', 0) * 100
relationship = detailed_calc.get('relationship_depth', {}).get('score', 0) * 100
```

### Product Attributes Used:
```python
fee = product.get('annual_fee', 0)
apy = product.get('interest_rate_apy', 0)
min_balance = product.get('min_balance', 0)
subcategory = product.get('subcategory', '')
```
