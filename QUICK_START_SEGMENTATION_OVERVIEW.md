# 🚀 Quick Start: Segmentation Overview Feature

**5-Minute Guide** to using the new hierarchical segmentation view

---

## 📋 Prerequisites (One-Time Setup):

### Step 1: Start Backend (if not running)
```bash
py -3.10 api/main_unified_chromadb.py
```

### Step 2: Start Frontend (if not running)
```bash
cd frontend
npm run dev
```

### Step 3: Load Data (if not loaded)
1. Go to `http://localhost:3000/academy/data-loader`
2. Click **"Load V1 Dataset"**
3. Wait for success message (~5 seconds)

### Step 4: Run Agent A (if not run)
1. Go to `http://localhost:3000/academy/agent-a`
2. Click **"Execute Agent A (5 clusters)"**
3. Wait for completion (~30-60 seconds)
4. You should see 4-5 persona cards

   📊 Complete Segmentation Overview
   NEW - DEMO VIEW

3. Click it!

### Option B: Direct URL

http://localhost:3000/academy/segmentation-overview

## 🖱️ How to Interact:

### View Macro Personas (Collapsed)
- Each card shows:
  - 🎯 Persona name (e.g., "🏕️ Beginner Budget-Conscious")
  - 📝 Description
  - 👥 Customer count and percentage
  - 💰 Revenue and avg spend
  - ⚡ Confidence score

### Expand to See Micro Segments
1. **Click any macro persona card**
2. Wait ~5-10 seconds (first time only)
3. See 2-3 micro segments appear
4. Each micro segment shows:
   - Name
   - Customer count
   - Avg spend
   - Key characteristics

### Collapse Back
- **Click the same card again** to collapse

### Expand Multiple at Once
- You can have multiple macros expanded
- Great for comparing micro segments across personas

## 🔍 Behind the Scenes:

### When you click "Expand":
1. Frontend sends POST request to create micro segments
2. Backend runs K-Means on that macro cluster
3. Returns 2-3 micro segments with characteristics
4. Frontend caches the result
5. Displays micro segment cards

### Why it takes 5-10 seconds the first time:
- K-Means clustering runs on the backend
- Analyzing 500-1000 customers per macro cluster
- Calculating characteristics and metrics
- Subsequent clicks are instant (cached)

### Data flow:
```
Frontend (Click) 
  → POST /api/academy/micro-segments/{cluster_id}
  → Backend runs K-Means
  → Returns micro segments
  → Frontend displays
  → Caches for future
```
