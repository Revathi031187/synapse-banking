## 🎯 Overview

The segment naming system now generates names **dynamically based on actual data characteristics**, not pre-defined generic labels. Names reflect what's REALLY in your dataset.

---

## 📊 How Dynamic Naming Works

### **Principle:**
Names are generated by analyzing the **strongest signals** in the actual data for each segment:
1. Dominant product category (from customer purchase history)
2. Strongest behavioral trait (bundle affinity, price sensitivity, frequency, expertise)
3. Actual spending patterns (from total_spend_12mo)
4. Real purchase frequency (from purchase_frequency field)

## 🏷️ Macro Segment Naming (2-3 words)

### **Data Analyzed:**

**File:** `agents/agent_a_academy_enhanced.py` (Lines 497-600)

```python
# Extract actual characteristics from data
specificity = characteristics['avg_search_specificity']  # 0-5 scale
bundle_affinity = characteristics['avg_bundle_affinity']  # 0-1
price_sort = characteristics['avg_price_sort_frequency']  # 0-1
avg_spend = characteristics.get('avg_spend_12mo', 0)  # Dollars
purchase_freq = characteristics.get('avg_purchase_frequency', 0)  # Times/year
dominant_cat = characteristics.get('dominant_category', '')  # Top category
```

### **Step 1: Extract Dominant Category from Data**

```python
# Map actual categories to natural names
category_names = {
    'Hiking Backpacks': 'Trail',
    'Sleeping Bags + Airbeds': 'Camp',
    'Tents': 'Shelter',
    'Camping Furniture': 'Comfort',
    'Coolers + Drinkware': 'Gear',
    'Footwear': 'Hiking',
    'Apparel': 'Outdoor'
}
category = category_names.get(dominant_cat, 'Outdoor')
```

**Result:** If segment mainly buys Tents → category = "Shelter"

---

### **Step 2: Find Strongest Behavioral Signal**

```python
# Compare all behaviors to find dominant one
behaviors = {
    'price': price_sort,              # e.g., 0.72 (high price sensitivity)
    'bundle': bundle_affinity,        # e.g., 0.45 (moderate bundling)
    'frequency': purchase_freq / 15,  # e.g., 0.53 (8 purchases/year normalized)
    'expertise': specificity / 5      # e.g., 0.34 (low expertise)
}

# Find which behavior is strongest
max_behavior = max(behaviors, key=behaviors.get)
```

**Result:** If price_sort = 0.72 is highest → max_behavior = "price"

---

### **Step 3: Generate Behavior Descriptor**

```python
if max_behavior == 'price' and price_sort > 0.5:
    behavior = "Deal"  # High price sensitivity
elif max_behavior == 'bundle' and bundle_affinity > 0.5:
    behavior = "Bundle"  # Loves bundles
elif max_behavior == 'frequency' and purchase_freq > 6:
    behavior = "Frequent"  # Shops often
elif max_behavior == 'expertise' and specificity > 3.5:
    behavior = "Expert"  # High product knowledge
else:
    # Use spend tier if no strong behavioral signal
    behavior = "Premium" or "Budget" or "Regular"
```

---

### **Step 4: Determine Actual Spend Level**

```python
# Based on ACTUAL average spend in data
if avg_spend > 1200:
    spend = "Elite"     # e.g., $1,500/year
elif avg_spend > 800:
    spend = "Premium"   # e.g., $950/year
elif avg_spend > 400:
    spend = "Mid"       # e.g., $600/year
else:
    spend = "Budget"    # e.g., $280/year
```

---

### **Step 5: Assemble Dynamic Name**

Names vary based on behavior type to sound natural:

```python
# Expert/Premium behavior → [Spend] [Category] [Type]
if behavior == "Expert":
    name = f"{spend} {category} Experts"
    # Examples: "Premium Trail Experts", "Elite Shelter Experts"
    
elif behavior == "Premium":
    name = f"{spend} {category} Buyers"
    # Examples: "Elite Camp Buyers", "Premium Gear Buyers"

# Deal/Budget behavior → [Category] [Behavior] [Action]
elif behavior == "Deal":
    name = f"{category} Deal Seekers"
    # Examples: "Trail Deal Seekers", "Shelter Deal Seekers"
    
elif behavior == "Budget":
    name = f"{category} Budget Shoppers"
    # Examples: "Camp Budget Shoppers", "Gear Budget Shoppers"

# Bundle behavior → [Spend] [Category] Bundlers
elif behavior == "Bundle":
    name = f"{spend} {category} Bundlers"
    # Examples: "Mid Trail Bundlers", "Budget Gear Bundlers"

# Frequent behavior → Frequent [Category] Buyers
elif behavior == "Frequent":
    name = f"Frequent {category} Buyers"
    # Examples: "Frequent Camp Buyers", "Frequent Hiking Buyers"

# Default → [Spend] [Category] Shoppers
else:
    name = f"{spend} {category} Shoppers"
    # Examples: "Mid Trail Shoppers", "Budget Outdoor Shoppers"
```

---

### **Step 1: Map Category from Data**

```python
category_map = {
    'Hiking Backpacks': 'Trail',
    'Sleeping Bags + Airbeds': 'Sleep',
    'Tents': 'Shelter',
    'Camping Furniture': 'Comfort',
    'Coolers + Drinkware': 'Gear',
    'Footwear': 'Hiking',
    'Apparel': 'Apparel'
}
category = category_map.get(dominant_category, 'Outdoor')
```

---

### **Step 2: Find Strongest Trait**

```python
# Compare all traits to find dominant one
traits = {
    'bundle': bundle_affinity,          # e.g., 0.32
    'frequent': purchase_freq / 15,     # e.g., 0.67 (10 purchases normalized)
    'loyal': brand_loyalty,             # e.g., 0.45
    'value': price_sensitivity,         # e.g., 0.28
    'expert': expertise                 # e.g., 0.71
}

# Find strongest
max_trait = max(traits, key=traits.get)
max_value = traits[max_trait]
```

---

### **Step 3: Generate Name Based on Strongest Trait**

```python
# Bundle trait strongest
if max_trait == 'bundle' and bundle_affinity > 0.15:
    name = f"{category} Bundlers"
    # Examples: "Trail Bundlers", "Sleep Bundlers"

# Frequency trait strongest
elif max_trait == 'frequent' and purchase_freq > 8:
    name = f"{tier} {category} Buyers"
    # Examples: "Premium Trail Buyers", "Budget Sleep Buyers"

# Loyalty trait strongest
elif max_trait == 'loyal' and brand_loyalty > 0.6:
    name = f"Loyal {category}"
    # Examples: "Loyal Shelter", "Loyal Gear"

# Value/price trait strongest
elif max_trait == 'value' and price_sensitivity > 0.15:
    name = f"{category} Savers"
    # Examples: "Trail Savers", "Gear Savers"

# Expertise trait strongest
elif max_trait == 'expert' and expertise > 0.6:
    name = f"{category} Pros"
    # Examples: "Shelter Pros", "Hiking Pros"

# No strong trait → use tier
else:
    name = f"{tier} {category}"
    # Examples: "Premium Trail", "Budget Gear"
```
