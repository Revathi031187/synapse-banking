## 💡 **New Utility Classes**

Use these throughout your app:

### **Buttons**
```tsx

<button className="btn-secondary">Secondary</button>
<button className="btn-success">Success</button>
```

### **Cards**
```tsx
<div className="card">
  <div className="card-header"><h2>Title</h2></div>
  <div className="card-body">Content</div>
</div>
```

### **Badges**
```tsx
<span className="badge badge-blue">Badge</span>
```

### **Inputs**
```tsx
<input className="input-field" />
```

3. **Restart Vite**: Stop and run `npm run dev` again
4. **Restart Backend**: Make sure backend is running on port 8002
